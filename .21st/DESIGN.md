# BridgeWay design context

Preserve the original referral templates: navy #10243c header, off-white #f5f4f0 canvas, white bordered cards, Georgia headings, compact sans-serif form labels, and the original practice logo. The patient page uses a two-column introduction/form layout collapsing on mobile. The staff page uses four monthly summaries, reporting chart/table, status filter tiles, patient inbox, office link management and email status.

The authoritative tokens and responsive rules are in src/bridgeway-web/app/globals.css. React components reuse these classes. The user requested the existing design, so no catalog components or generated visual alternatives were adopted.
